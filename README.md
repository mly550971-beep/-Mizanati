# ميزانيتي — Personal Expense & Budget Tracker

واجهة عربية RTL لتسجيل الدخل والمصروفات ومتابعة الميزانية الشهرية. المشروع مبني باستخدام HTML وCSS وJavaScript فقط، ولا يحتاج إلى Node.js أو تثبيت مكتبات.

## ملفات المشروع
- `index.html`: هيكل الصفحة.
- `style.css`: التصميم المتجاوب والألوان والحركات.
- `script.js`: إضافة وحذف المعاملات، الفلاتر، الإحصائيات، الرسم البياني، وحفظ البيانات محليًا.

## التشغيل محليًا
1. نزّل ملفات المشروع أو فك ضغط ملف ZIP.
2. احتفظ بالملفات الثلاثة في مجلد واحد.
3. افتح https://mly550971-beep.github.io/-Mizanati/
## النشر باستخدام GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع `index.html` و`style.css` و`script.js` و`README.md` إلى جذر المستودع.
3. افتح **Settings → Pages** في المستودع.
4. ضمن **Build and deployment** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واضغط **Save**.
5. انتظر اكتمال النشر، ثم افتح الرابط الذي سيظهر في صفحة Pages.

## ملاحظات مهمة
- البيانات محفوظة في `localStorage` داخل المتصفح نفسه؛ لا توجد مزامنة بين الأجهزة ولا حسابات مستخدمين أو قاعدة بيانات.
- لا تستخدم النسخة الحالية لحفظ معلومات مالية شديدة الحساسية؛ مسح بيانات المتصفح قد يؤدي إلى فقدان السجلات.
- يعتمد الخط Cairo على Google Fonts عند توفر الإنترنت، مع خط بديل عند تعذر الاتصال.
