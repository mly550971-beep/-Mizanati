# ميزانيتي — Personal Expense & Budget Tracker

واجهة عربية RTL لتسجيل الدخل والمصروفات ومتابعة الميزانية الشهرية. المشروع مبني باستخدام HTML وCSS وJavaScript فقط، ولا يحتاج إلى Node.js أو تثبيت مكتبات.

## ملفات المشروع
- `index.html`: هيكل الصفحة.
- `style.css`: التصميم المتجاوب والألوان والحركات.
- `script.js`: إضافة وحذف المعاملات، الفلاتر، الإحصائيات، الرسم البياني، وحفظ البيانات محليًا.

## التشغيل محليًا
1. نزّل ملفات المشروع أو فك ضغط ملف ZIP.
2. احتفظ بالملفات الثلاثة في مجلد واحد.
3. افتح https://mly550971-beep.github.io/-Mizanati/
